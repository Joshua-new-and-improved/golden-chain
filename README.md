# Golden Chain

A free Catholic study site: the whole Douay-Rheims Bible with the Church Fathers, St Thomas Aquinas's Golden Chain and Haydock's commentary on almost every verse; daily Mass readings with exegesis (South African calendar); a course in Thomistic theology; disputed questions; apologetics; life's questions; and prayers.

Live site: https://joshua-new-and-improved.github.io/golden-chain/

AI-prepared study aid. Not an official Church resource.
